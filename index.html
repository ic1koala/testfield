Hikari Guide Designer Manual

1. 基本操作モード

  • DESIGN (EDIT) モード: パーツの配置、移動、サイズ調整、プロパティ変更を行います。
  • SIMULATE モード: 仮想PLCと同期し、デバイスの値の変化に連動してUIの表示が変化する様子を模擬します。

2. UIオブジェクトの操作とショートカット

  • 選択したオブジェクトは、マウスでドラッグして移動できます。
  • 選択時に右下に表示されるハンドルをドラッグすると、サイズを変更できます。
  • 四角形パーツ: 縦横を自由に引き伸ばしてサイズ変更できます。
  • 丸型パーツ (Bit Lamp): 縦横比率を維持したまま、均等にサイズ変更されます。
  • グリッドスナップ: Shiftキー を押しながら移動やリサイズを行うと、一定間隔（10px）で吸着し、整列しやすくなります。
  • 削除ショートカット: オブジェクトを選択した状態で Delete または Backspace キーを押すと即座に削除できます。

3. プロパティと重なり順 (Z-Index)

  • 右側のパネルから、割り当てるデバイスやテーマカラー、被写界深度 (Depth) などを変更できます。
  • オブジェクトが重なっている場合は、パネル下部の Bring Front (前面へ) / Send Back (背面へ) ボタンで重なり順を調整できます。

4. Depth Control (被写界深度設定)

  • DESIGNモード中、トグルの直下にある「Depth Control」ボタンを押すと、画面全体がグレースケールの被写界深度（±20mm）マップに切り替わります。
  • グレー背景が基準面（0mm）で、明るい部分が手前に突出し（最大+20mm）、暗い部分が奥に凹んでいる（最小-20mm）ことを表現します。

5. PLC Device Registry とシミュレーション

  • 画面右上の「PLC Device Register」ボタンから、現在使用中のデバイス一覧を確認できます。
  • 一覧内で直接、デバイスの割り当てや Object ID（名称）を変更することが可能です。
  • SIMULATEモードに移行し、仮想PLC操作盤から状態を変化させて連動テストを行います。
